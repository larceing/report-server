Report Server

Subir una plantilla

Un documento de Word (.docx), LibreOffice (.odt) o Excel (.xlsx, .ods) con marcas como {d.cliente}. Con un nombre que ya existe, la sustituye y conserva sus datos de ejemplo.

«Copiar la llamada» da lo que otra app tiene que mandar a /api/generar para este documento.

ResultadoDescargar

Pulsa «Generar» para verlo con los datos de ejemplo.

CuándoAppPlantillaFormatoTamañoTiempoEstado

Cada app que genera documentos tiene su llave. Se ve una sola vez: guárdala en el app.env de esa app como REPORT_LLAVE, junto con REPORT_URL=http://report-server-<entorno>:3000.

AppCreadaÚltimo uso

Una plantilla es un documento normal de Word, LibreOffice o Excel: le das el diseño que quieras (logo, colores, tablas) y escribes marcas donde van los datos. Report Server las rellena con lo que manda la app y saca el PDF.

Marcas

{d.cliente.nombre}Un dato. d son los datos que manda la app.
{d.lineas[i].concepto}
{d.lineas[i+1].concepto}		Una lista: en una fila de tabla la primera marca y en la fila de debajo la misma con i+1. Se repite la fila por cada elemento.
{d.total:formatC(2)}Moneda: 1.234,50 €
{d.horas:formatN(2)}Número con decimales: 6,75
{d.fecha:formatD('DD/MM/YYYY')}Fecha (la app la manda como 2026-10-12)
{d.notas:ifEmpty('Sin notas')}Texto si viene vacío
{d.lineas:len()}Cuántos elementos tiene una lista

Todas las marcas en la documentación de Carbone. Consejo: escribe cada marca de una vez, sin corregirla a medias, para que Word no la parta por dentro.
